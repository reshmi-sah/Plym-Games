# PLYM Games – Frontend Technical Assessment

This project is a frontend UI implementation created as part of **Round 2 – Technical Assessment (Frontend Development)** for **PLYM Games**.
The task was to recreate and enhance a provided reference UI into a responsive, clean, and interactive frontend application using modern frontend practices.

---
## 🚀 Live Demo
👉 Live URL: https://plym-games.netlify.app/

## 🛠 Tech Stack
- **React.js**
- **Tailwind CSS**
- **Vite**

## 📂 Project Structure
src/
│
├── components/
│   ├── Badge.jsx        # Reusable status badges
│   ├── Card.jsx         # Reusable dashboard cards
│   └── features.js      # Feature data configuration
│
├── sections/
│   ├── Header.jsx       # Top status section
│   ├── HeroContent.jsx  # Main left content
│   └── DashboardPanel.jsx # Right dashboard panel
│
├── pages/
│   └── Home.jsx         # Main page layout
│
├── App.jsx
├── main.jsx
└── index.css

Features
Responsive single-page layout
Clean and modular component structure
Gradient-based modern UI
Reusable components for scalability
Smooth hover effects and transitions
Mobile-first design approach

Design Approach
The page is divided into sections (Header, HeroContent, DashboardPanel) for layout clarity.
Reusable components (Badge, Card) are used where repetition and consistency are required.
Avoided over-engineering while maintaining a production-ready structure.
Focused on readability, maintainability, and UI polish.
